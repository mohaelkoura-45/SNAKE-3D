SNAKE 3D  -  a complete 3D snake game in a single Python file.

Requirements:   pip install pygame        (pygame-ce works too)
Run:            python snk.py

MODES      Adventure (25 stages, 5 bosses) - Classic (original 10 levels) - Time Attack
           Survival - Challenge - Daily Challenge
CONTENT    26 maps, 20 worlds, 20 characters, 12 fruits, 10 power-ups, 5 events, 22 music tracks
PROGRESS   XP / levels (cap 100), coins, shop, missions (50+), achievements (30+),
           daily challenge, login streak, profile, JSON save with backup + recovery

CONTROLS
  Arrows / WASD ... steer (relative to the screen; in Chase cam: turn left/right)
  Q / E ........... rotate camera          Mouse drag ..... orbit / tilt  (in game)
  Mouse wheel ..... zoom (game) / scroll (menus)   V ... camera mode
  N / B ........... next / previous track  M ............. mute all
  P / Esc ......... pause / back           F11 ........... fullscreen
  Menus: arrows + Enter, or just use the mouse.
